# Fase-4-Programacion

Orden de construcción propuesta

Esta será nuestra ruta de trabajo:
1. Primera etapa: configuración y excepciones
   Definir tarifas, excepciones personalizadas y sistema de logs.
   
3. Segunda etapa: entidades y clientes
   Implementar abstracción, encapsulación, identificaciones y validaciones.
   
5. Tercera etapa: servicios
   Construir las clases abstractas y especializadas con polimorfismo y cálculos de costos.
   
7. Cuarta etapa: reservas
   Asociar clientes y servicios, controlar disponibilidad, confirmar, cancelar y procesar.
   
9. Quinta etapa: sistema central
   Crear el menú, administrar las listas y coordinar todas las operaciones.
   
11. Sexta etapa: pruebas integrales
   Ejecutar las 13 operaciones propuestas, incluyendo errores y recuperación del sistema.

11. Séptima etapa: revisión final
   Comprobar excepciones, logs, modularidad y funcionamiento general.
